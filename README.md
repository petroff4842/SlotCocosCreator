SlotCocos

Simple slot game test task implemented with Cocos Creator 3.8.8 and TypeScript

Features:
	5 reels × 3 visible symbols
	10 paylines
	Wild symbol substitution
	Win calculation based on paytable
	Reel spin and stop animations using Cocos Tween
	Win counter animation
	Winning symbol highlighting
	MVC architecture

Tech Stack:
	Cocos Creator 3.8.8
	TypeScript
	Cocos Tween

How to Run:
	Open the project in Cocos Creator 3.8.8
	Open assets/main_scene.scene
	Click Preview or create a Web Desktop Build

Assets:
	Visual assets used in this project were generated with AI tools and are included for demonstration purposes only
